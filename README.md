## What I'm working on

**News Credibility Analyser**
A fake news classifier trained on 38,000+ articles, using TF-IDF and Logistic Regression, deployed with Streamlit. Every prediction ships with the words that drove it, pulled straight from the model's coefficients — so it's never a black-box verdict. While testing it against a legitimately-reported article, I found the model quietly learning to detect *source formatting* instead of content: it had latched onto the word "reuters" and leftover photo-caption text as shortcuts for "credible." I traced the leak back to preprocessing, fixed it, and wrote it up in the repo instead of quietly patching it and moving on.

**AI RAG Chatbot**
A retrieval-augmented generation system built with LangChain, ChromaDB, and Google Gemini, grounded in Hugging Face embeddings. This project taught me that a language model is only as good as what it can look up — getting retrieval right, chunking, embedding, matching, matters more than the prompt sitting on top of it.

**AI Gym Fitness Assistant**
A fitness application combining workout tracking, diet planning, and a webcam-based trainer with habit analytics. The hard problem here wasn't the AI, it was the interface: turning tracked data into something a person would actually open again tomorrow.
